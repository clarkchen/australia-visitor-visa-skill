# 材料与一致性检查

## 按证明事项收集，不按成功案例照搬数量

| 证明事项 | 可考虑的材料 | 复用时的判断 |
|---|---|---|
| 身份 | 当前护照、身份证、户口簿 | 护照为身份基准，补充材料按系统和实际情况提供 |
| 同行及家庭关系 | 与实际关系对应的材料，如适用的结婚证、户口簿 | 区分持证人与当事人，逐人核对，不由文件名推断归属 |
| 实际访问目的 | 说明信、个人或共同行程；参会或陪同时另加相关证明 | 按场景选材料，纯旅游不要求会议证明，不混写同行者身份 |
| 工作及回国安排 | 签字盖章在职准假信、个税、社保 | 核对单位、职位、入职日、收入口径和准假日期 |
| 资金 | 连续银行流水、存款证明 | 说明费用来源与承担；资产不能代替可用资金 |
| 国内联系 | 工作、家庭、住宅等实际证据 | 核对权利人及共有记载，不从夫妻关系推断本人拥有房产；房车是补充 |
| 旅行历史 | 旧护照、旧签证、出入境记录 | 获签与实际旅行分开表述，拒签必须归属本人 |
| 其他 | 学历、家庭成员表等 | 以系统要求及证据价值决定，不一律要求 |

工作及准假材料仅适用于对应身份；退休、在读、自雇等按实际情况提供替代证据，不默认所有人都有单位。

## 银行流水的处理经验

根据本次流水覆盖区间和银行标记识别工资，可生成保留原版式的高亮副本和带源页码的工资英文摘要。页数、月份和笔数从当前文件提取，不硬编码。

工资结合交易描述、付款方及在职/工资单等证据交叉核实；标记不明确时不能仅凭金额或定期入账判断，本人账户调拨、定期支取、证券账户转账、夫妻间转账不自动算新增工资。大额交易先查来源，无法解释时标记待核实，不杜撰来源。

源文件完整保留，所提交非英文材料默认配完整英文译件。工资摘要应注明范围和源页码，仅作辅助索引；没有适用官方依据时不能用摘要取代译件。原脚本含姓名、账户和单位，不直接移入通用仓库。

## 证件人物对应

结婚证、房产证等按 [证件人物对应流程](person-document-linkage.md) 检查持证人、当事人、权利人/共有人及申请人的关系。名字出现在证上不等于本册由其持证；配偶名下证件也不等于本人名下财产。记录角色、身份关联依据、原件/译件页码及能支持的陈述，再确定用途。

## 译件核验

- 户口簿、证件正反面、印章、登记栏和附注都核对；难辨处标为无法辨认。
- 译者姓名、地址、电话、语言资格和经验按官方适用要求真实填写。
- 如译者与申请人有亲属关系，应如实披露；历史语言成绩不能表述为专业翻译认证。
- 不能从个案获签推断普遍认可亲属翻译或局部翻译；应重新核实。
- 译者详情页更新需替换旧页，避免每次运行重复追加。

## 最终检查顺序

1. 分人核对身份和签证历史，排除配偶文件误归属；对结婚证持证人/当事人及房产证权利人/共有人作明确对应，并与译件及说明信比对。
2. 检查跨时区旅行日期，区分出发与抵达日。
3. 检查申请表、说明信、在职准假信和共同日程是否一致。
4. 按人、费用项目、承担者、金额/预算和证据核对资金安排，包括配偶资助与单位覆盖双方的实际情形。检查可用资金与合理预算是否对应；不将税前收入、净工资及账户调拨直接相加。
5. 检查每份原件的译件对应、翻译范围和签字状态。
6. 对照真实系统类别整理上传清单，排除过期行程、重复件及草稿。
7. 将仍未确认的签字、递交、缴费等状态列出，不因获签而补写历史勾选。

## 扫描件与上传版

按 [图像与上传检查](scans-and-upload.md) 核对原始扫描和最终上传文件。OCR 成功不代表清晰度合格；压缩/合并后重新逐页查看，并检查最终字节数与实际上传栏的格式、大小、数量限制。使用 [附件检查表](../assets/attachment-review.md) 分别记录检查状态。
